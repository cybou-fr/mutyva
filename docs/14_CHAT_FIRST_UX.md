# MUTYVA: приложение и чат

Актуальное продуктовое решение, 19 октября 2026.

## Основной сценарий

Пользователь видит работающее приложение и кнопку **«Чат с AI»**. Кнопка открывает боковую панель. В ней пользователь входит через ChatGPT, пишет обычными словами, читает ответ или уточнение. Когда изменение готово, чат закрывается, чтобы показать будущий интерфейс. Пользователь нажимает «Применить» или «Отмена». После применения приложение сохраняется и работает без AI.

Пользователь не собирает контекст, не выбирает компоненты из каталога, не вставляет JSON и не настраивает промпты. История конфигурации, схемы, палитра, SQL, модели и проверка операций — внутренние механизмы. Они не становятся обязательными шагами основного сценария.

## Что видно пользователю

- Рабочий инструмент и кнопка чата; «О MUTYVA» и атрибуция источников.
- Continue with ChatGPT, состояние подключения, отмена входа и выход.
- Сообщения пользователя и понятные ответы AI, поле запроса, отправка/отмена запроса.
- Предпросмотр будущего интерфейса и явное подтверждение изменения.
- Понятная ошибка и возможность повторить действие.

Поколения, JSON, ручные операции, демонстрационные кнопки и инспектор контекста скрыты. Для разработки их можно открыть **Ctrl+Shift+D**. Документация разработчика может описывать эти инструменты; пользовательская инструкция начинает с чата.

## Скрытый процесс

AiChat автоматически строит контекст для текущего сохранённого интерфейса. DesignerContext добавляет концепцию, каталог, декларацию, схемы и доверенные инструкции. В запрос также входят недавние сообщения диалога. LocalDataStore, токены, путь базы и значения пользовательских полей/списков не включаются. Начальные значения в декларации и вручную записанные в ней строки включаются.

AI возвращает предложение, уточнение или объяснение ограничения. Хост проверяет полный ответ, версию исходного интерфейса и допустимость операций. Частичный ответ, ошибка потока или устаревший результат не меняют приложение. Даже корректное предложение создаёт только предпросмотр. Применение выполняет пользователь.

## Текущее состояние и границы

UI чата связан с ChatSession и AiChat. Реализованы Windows-вход через браузер, проверка идентификации, запрос доступных моделей и потоковый Responses-запрос. Это первая интеграция: реальный вход/ответ на подходящем аккаунте ещё нужно проверить вручную. Офлайн-тесты не доказывают доступность сервиса или право конкретного аккаунта.

Сеанс и последние 24 сообщения хранятся в памяти. После закрытия нужен новый вход; обновление токенов и защищённое долговременное хранилище ещё не реализованы. Host ID и регистрация выбранного аккаунта сохраняются без токенов. Сейчас поддерживается одна регистрация; полноценный выбор нескольких аккаунтов — следующий этап. Поддержка криптографической проверки в других ОС также остаётся работой.

Настройка API-ключа, модели или endpoint не предлагается пользователю. Отправка доступна после проверенного входа. Ни одна сетевая операция AI не начинается автоматически при запуске.

## Приёмка

Открыть приложение → «Чат с AI» → Continue with ChatGPT → согласие в браузере → запрос → ответ/уточнение → предпросмотр → Применить → перезапуск без AI.

Полная приёмка требует реального аккаунта. Не объявлять OAuth/AI проверенными end-to-end до выполнения этой цепочки. См. [03_CHATGPT_AUTH.md](03_CHATGPT_AUTH.md) и [15_AI_CONNECTION.md](15_AI_CONNECTION.md).
