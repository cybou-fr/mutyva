# Общая палитра и декларации v2

Кроме пяти компонентов погоды, runtime содержит семь общих видов:

| kind | Свойства | Поведение |
|---|---|---|
| text | title, text | Обычный текст без HTML/выражений |
| card | title | Контейнер с фоном |
| stack | title | Вертикальный контейнер |
| row | title | Строка; при недостаточной ширине превращается в колонку |
| input | title, value, placeholder | Текстовое поле до 500 символов |
| list | title, items | До 50 строк по 500 символов |
| button | title, action | Явное пользовательское действие; без action неактивна |

## Вложенность

`schemaVersion: 2`. Массив widgets остаётся плоским, ID уникальны для всего документа. Свойство parent ссылается на ID card, stack или row. Без parent (или с пустой строкой) элемент находится в корне. Порядок соседей определяется их порядком в widgets. Разрешено до 100 виджетов и до 8 уровней дерева; циклы, неизвестные parent и родители, не являющиеся контейнерами, отклоняются.

Старые документы v1 сначала проверяются по сохранённой схеме app-v1. При успешном открытии runtime сохраняет эквивалентную декларацию v2 новым поколением, не меняя исходный файл поколения. Повторное открытие v2 не создаёт ещё одну миграцию. Проверенные старые мутации v1 также могут применяться с результатом v2. Повреждённый документ не мигрирует. При ошибке записи старый HEAD остаётся активным.

## Действия

Кнопка принимает только один из двух контрактов:

```json
{"kind":"append-item","input":"noteInput","target":"notesList"}
```

```json
{"kind":"clear-list","target":"notesList"}
```

input должен ссылаться на поле input, target — на list того же документа. Добавление пустой строки и переполнение списка отклоняются без изменения данных. Успешное добавление очищает поле ввода. Нет произвольных выражений, URL, SQL, кода и новых сетевых разрешений.

`InteractionState` держит пользовательские значения отдельно от декларации. Ввод и действия не создают поколений и не записываются в контекст AI. В предпросмотре общие поля/кнопки отключены, показываются начальные значения кандидата. После Apply отображаются значения сеанса для сохранившихся ID. Перестановки и изменение подписей не сбрасывают эти данные.

**Ограничение этого этапа:** пользовательские значения и списки живут только до закрытия процесса. После запуска снова используются value/items из декларации. Это не постоянное хранилище заметок. Удаление компонента или смена его kind сбрасывает его данные сеанса; предпросмотр удаления предупреждает об этом. Сохранение бизнес-данных — отдельный следующий слой; откат конфигурации не должен откатывать эти данные.

## Мутации и редактор

- updateProperty допускает только свойства, перечисленные у конкретного kind в каталоге, с проверкой типа и лимитов.
- moveWidget может содержать parent для переноса между контейнерами. after ссылается только на соседа в том же parent; пустая строка означает начало.
- addWidget задаёт parent внутри widget. Если after отсутствует, элемент добавляется в конец своего контейнера.
- removeWidget удаляет поддерево контейнера целиком. Предпросмотр перечисляет все удаляемые ID. Ссылки действий из оставшихся компонентов должны оставаться валидными; иначе весь пакет отклоняется.

«Изменить интерфейс» позволяет выбирать свойства из каталога, редактировать строки, задавать items/action через JSON и переносить выбранный компонент в контейнер. Дополнительные операции доступны в JSON-редакторе и через контракт дизайнера.

## Проверка примера

Нажать «Пример: заметки», проверить предпросмотр и нажать «Применить». Карточка собирается из всех семи общих видов, кнопки добавляют заметку и очищают список без AI. `examples/general-workspace.mutyva.json` содержит ту же композицию вместе с погодой. Операция заменяет конфигурацию демо на образец и показывает все изменения перед применением.

Тесты проверяют миграцию, свойства по видам, повреждённые ссылки, циклы, глубину, удаление поддерева, действия, лимиты, отсутствие записи данных сеанса в историю/контекст AI, рекурсивную QML-отрисовку и узкое окно. Table, пользовательские формулы, произвольные привязки, постоянное хранилище данных, сетевой AI и RAD drag-and-drop здесь не реализованы.
