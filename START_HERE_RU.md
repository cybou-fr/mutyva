# MUTYVA — с чего начать разработку MVP

![MUTYVA — One App. Infinite Forms.](branding/exports/mutyva-logo.png)

Исходники фирменного стиля, иконки платформ и инструкция по экспорту: [branding/README.md](branding/README.md). В приложении доступны приветствие и «О MUTYVA».

**Обновлено:** 19 октября 2026.
**Продукт:** одно приложение на Qt 6/QML/C++20, которое меняет свою форму по запросу пользователя через ChatGPT, сохраняет все удачные изменения и затем работает без AI.

## Как пользователь работает с приложением

Запускает MUTYVA → нажимает **«Чат с AI»** → **Continue with ChatGPT** → завершает вход в браузере → описывает задачу словами → смотрит предпросмотр → подтверждает изменение. JSON, палитра, схемы и подготовка контекста скрыты. Технические инструменты открываются только через Ctrl+Shift+D.

Windows-вход и реальная цепочка AI проверены 19 октября 2026: автоматический тест получил ответ, выполнил мутацию во временном приложении и восстановил сохранённое поколение. Токены и чат сейчас только в памяти; после перезапуска требуется вход. Подробности: [docs/14_CHAT_FIRST_UX.md](docs/14_CHAT_FIRST_UX.md), [docs/15_AI_CONNECTION.md](docs/15_AI_CONNECTION.md).

## Что мы строим

Не отдельную ОС, не платформу облачных аккаунтов и не генератор EXE. MUTYVA — **универсальная локальная среда выполнения**, способная превращаться в CRM, панель аналитики, файловый инструмент и т. д. Каждое «приложение» — декларативное описание компонентов, данных и действий. Работает локально, сохраняет поколения, ChatGPT вызывается только для проектирования/изменения.

### Состав MVP

- Qt 6.8+, QML, Qt Quick Controls, C++20, CMake.
- Базовое приложение **City Pulse**, работающее с открытыми API без ключей: города, температура, прогноз на неделю и качество воздуха.
- Локальная декларация JSON, палитра проверенных компонентов, редактор мутаций.
- Локальная история успешных поколений, восстановление и автономный запуск уже сохранённого GUI.
- Официальная авторизация **Sign in with ChatGPT**, без API-ключа, если условия подписки и программы позволяют использовать этот маршрут.
- Первый AI-запрос: «Добавь карточку влажности после прогноза». Модель возвращает изменение JSON, MUTYVA проверяет его, показывает предпросмотр и применяет только после подтверждения.
- Начало с Windows, затем Android; поддержка Linux/macOS/iOS заложена, но на них ещё потребуется отдельное тестирование.

### Чего в MVP НЕ БУДЕТ

Никаких собственных серверов, репозиториев компонентов, аккаунтов MUTYVA, синхронизации, Ollama, альтернативных моделей, компиляции генерируемого кода, тяжёлого редактора, собственного ядра или обвязки AOSP.

## Порядок запуска проекта

**Шаг 1. Запусти базовую демонстрацию.** Открой `CMakeLists.txt` из корня архива в Qt Creator, выбери установленный Qt 6.8+ kit и собери проект. Или в настроенном Qt окружении выполни:

```bash
qt-cmake -S . -B build
cmake --build build --config Release
```

Пример работает с Open-Meteo по HTTPS. В коде есть QML-виджеты и C++ сервис, получающий реальные данные. **Первая Windows-интеграция ChatGPT OAuth/Responses написана; реальная проверка с аккаунтом пройдена 19 октября 2026.**

**Шаг 2. Проверь декларативность.** Файл `examples/city-pulse.mutyva.json` описывает виджеты. Кнопка `+ Виджет влажности` загружает пример JSON-мутации, проверяет его и показывает будущий интерфейс. Нажми «Применить» для сохранения поколения или «Отмена». После применения перезапусти приложение: виджет останется без AI.

**Шаг 3. Проверь редактор и Mutation Engine.** Уже реализован общий путь `validate -> preview -> apply -> commit` для четырёх операций: добавить, удалить, изменить заголовок и переместить. Открой «Изменить интерфейс»; редактор JSON принимает декларацию или мутацию. Неизвестные компоненты, повтор ID, неверные свойства и разрешения отклоняются. Тесты: `ctest --test-dir build-msvc -C Release --output-on-failure`. Следующая работа — полноценный браузер поколений с метаданными и восстановлением выбранной версии.

**Шаг 4. Проверь вход и диалог с ChatGPT из кнопки чата.** Полный план — `docs/03_CHATGPT_AUTH.md`. Он учитывает dynamic client registration, уникальный host ID, Authorization Code + PKCE, nonce/state, проверку ID-токена, scopes, безопасное хранение/обновление токенов, подбор доступной модели и streaming Responses API с `store:false`, `stream:true`. Проверить на реальном подходящем аккаунте; нельзя обходить через cookies или неофициальные endpoint'ы.

**Шаг 5. Сквозной пользовательский сценарий.** Пользователь открывает City Pulse, авторизуется, говорит «Добавь карточку влажности», видит безопасный diff, нажимает Apply, закрывает приложение и запускает его без AI. Карточка живёт и обновляется от Open-Meteo.

## Важные честные ограничения

- Windows-сборка проверена с Qt 6.12 / MSVC 2022. Проверки деклараций, операций, предпросмотра, отмены, перезапуска и QML выполняются через Qt Test в изолированных временных папках. Другие платформы ещё не проверены.
- Первая Windows-интеграция Sign in with ChatGPT и Responses написана и проверяется офлайн-тестами. **Реальный вход, ответ и AI-мутация проверены сквозным тестом на одном аккаунте Windows**; постоянные сеансы и автоматический refresh пока не реализованы.
- Free API Open-Meteo разрешено использовать **некоммерчески** с соблюдением условий и атрибуции; платный или коммерческий релиз требует другого режима лицензирования.
- Qt заявляет поддержку всех пяти ОС, но кроссплатформенность самого MUTYVA должна подтверждаться сборками и устройствами. Для iOS понадобится macOS/Xcode; мобильный OAuth callback обязательно протестировать.
- История поколений откатывает **конфигурацию GUI**, а не побочные эффекты в удалённых сервисах.

## Один тест, определяющий успех MVP

**Человек, не написав ни строчки кода, изменил внешний вид работающего приложения словами; система безопасно сохранила изменение; после перезапуска без ChatGPT приложение осталось работающим.**
